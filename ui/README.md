# ui — фронт пульта `videoforge ui`

Просмотрщик поверх файлов конвейера. Данные отдаёт FastAPI в `videoforge/api/`
(`data.py` собирает словари из папок, `app.py` — маршруты `/api/…` и медиа
`/files/<корень>/…`). Своего состояния у фронта нет: всё, что он показывает,
лежит в `projects/`, `resources/`, `research/`, `library/`, `accounts/`,
`features/`. План и вторая очередь — `docs/UI_PLAN.md`.

## Команды

```powershell
# из корня репозитория
uv run videoforge ui            # API на 8765 + раздача ui/dist (если собран)
.\check.ps1 ui                  # npm install при необходимости + npm run build → dist/

# из ui/ — разработка с горячей перезагрузкой
npm run dev                     # Vite на 5173, /api и /files проксируются на 8765
npm run typecheck               # tsc --noEmit (build делает то же перед vite build)
```

Другой адрес бэкенда: `VF_UI_BACKEND=http://host:port npm run dev`.

## Стек

Vite + React 19 + TypeScript + Tailwind 4, TanStack Query (запросы и кэш),
react-router (страницы), Recharts (график подписчиков), react-markdown +
remark-gfm (rules.md, LOG.md, README источников), lucide-react и simple-icons
(иконки). shadcn-CLI нет: примитивы свои, в `src/components/ui/primitives.tsx`.

## Структура `src/`

| файл | что |
|---|---|
| `api.ts` | типы ответов API и функции запросов. **Типы повторяют словари `videoforge/api/data.py`** — новое поле там → сюда |
| `App.tsx`, `main.tsx` | маршруты и монтирование |
| `components/Layout.tsx` | навигация и каркас страницы |
| `components/common.tsx` | `PageHeader`, `Stat`, `Section`, `Details`, `StatusPill`, `MediaModal` (просмотр кадра / клипа / озвучки; проп `montage` добавляет вкладку с таймлайном) |
| `components/VideoShelf.tsx` | полка роликов: длинные строками, шортсы сеткой |
| `components/PlanEditor.tsx` | правка плана монтажа (музыка, затухания, переходы). Что можно менять, решает сервер (`api/planedit.py`), форма только показывает поля белого списка и честно печатает, что ответил линт |
| `components/Montage.tsx` | монтажный вид: плеер + дорожки на одной шкале. Курсор двигает `requestAnimationFrame` и пишет прямо в `style` (в React уходит только смена активного элемента), волна рисуется в canvas шириной с ЭКРАН и едет за прокруткой — во всю длину таймлайна браузер её обрежет молча |
| `components/ui/primitives.tsx` | кнопки, карточки, бейджи, таблицы |
| `lib/icons.ts` | **одна карта иконок**: стадии, области фич, виды ресурсов, типы файлов, сети, точки решения. Новая сущность = строка здесь, не иконка на месте |
| `lib/format.ts` | форматирование чисел, дат, длительностей, денег |
| `pages/*.tsx` | по странице на маршрут: аккаунты → аккаунт, проекты → проект → эпизод, тесты (галерея проверочных роликов проектов с `kind: test`, плеер прямо на странице), ресурсы → вид → ресурс, библиотека → точка → приём, замеры (`_bench`) → тест → файл, возможности (карта конвейера, порядок стадий — `FLOW` в `Capabilities.tsx`), планы → запись |

## Как добавить страницу

1. Сборщик в `videoforge/api/data.py` над существующими файлами и маршрут в
   `app.py` (новый формат файлов не заводить — см. дизайн-заметки (приватные, не опубликованы)).
2. Тип ответа и функция запроса в `src/api.ts`.
3. Страница в `src/pages/`, маршрут в `App.tsx`, пункт навигации в `Layout.tsx`.
4. Иконка сущности — строка в `lib/icons.ts`; заголовок, счётчик и раздел берут
   её через `PageHeader` / `Stat` / `Section`.
5. Подписи и подсказки — по-русски, без жаргона: человек читает карточку сцены
   без английского.
6. Тест API — `tests/test_api.py` (TestClient на тех же фикстурах).

## Телефон: страница не ездит вбок

Пульт смотрят с телефона, поэтому **горизонтальной прокрутки у страницы быть не
должно** — вбок ездят только свои коробки (полоса меню, таблица, таймлайн). Ломают
это две вещи: текст из файлов с длинным куском без пробелов (путь, id, команда) и
элемент фиксированной ширины в тесном ряду. Первое лечит общее правило в
`index.css` (`overflow-wrap: break-word`), второе — `min-w-0` соседям в ряду и
раскладка в один столбец на узком экране (`max-md:`).

Проверяется замером, а не на глаз: открыть страницу шириной 375 и сравнить
`document.documentElement.scrollWidth` с `clientWidth` — разница и есть «уехало
вбок». Виновника показывает перебор элементов, у которых правый край правее
экрана, а ни один предок их не обрезает.

`dist/` и `node_modules/` в репозиторий не попадают (`ui/.gitignore`);
`videoforge doctor` показывает, собран ли фронт.
