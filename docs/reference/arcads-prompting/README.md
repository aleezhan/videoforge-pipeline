# Справка: промптинг из arcads-claude-code

Отобранные файлы из [krusemediallc/arcads-claude-code](https://github.com/krusemediallc/arcads-claude-code)
(MIT, © 2026 Caleb Kruse / Kruse Media LLC — см. `LICENSE` рядом; снято 2026-08-28).
Источник — воркспейс для генерации рекламных роликов через API Arcads. Его
архитектура (агент рулит генерацией напрямую) нам не подходит, но промпт-гайды
и пара рецептов — переносимы. API-детали Arcads в файлах игнорировать: нам
интересны только правила промптинга и QA-чеклисты.

**Это справка, не код.** Ничего отсюда не импортируется; когда идея переезжает
в `stages/prompts.py`, `stages/portfolio.py` или `assemble` — переносим смысл,
а не копипасту, и адаптируем под нашу раскадровку.

> Уточнено 15.09.2026: «будущие субтитры в `assemble`» в таблице ниже —
> прошедшее время. Субтитры сделаны 03.09: `core/captions.py` группирует
> пословные тайминги edge-tts в реплики и пишет ASS с караоке, `assemble`
> рисует его через libass. Обходной путь «Pillow + overlay вместо libass»
> (`render-captions.py`) не понадобился: в нашем ffmpeg libass есть, нет
> только fontconfig, поэтому папка шрифтов задаётся явно. Провайдер картинок
> у нас не Nano Banana, а `comfy` (klein 4B + LoRA на своей карте) или
> `gemini`; QA-чеклисты из справки остаются полезными как были.

## Сквозные идеи, которые подтверждают/дополняют наши принципы

- **Дословность вместо пересказа.** Описание персонажа, стиля и продукта
  копируется побайтово во все промпты — любая перефразировка = другой персонаж.
  Это ровно наш `prompt_block`, у них — подтверждение на продакшен-прогонах.
- **Якорь — только утверждённый кадр.** Image-to-video всегда от одобренного
  стилла, никогда от кадра предыдущей анимации (дрейф накапливается).
- **QA с капом ретраев и точечной поправкой.** Перегенерация — с новым
  констрейнтом, называющим дефект («exactly five fingers each»), не повтор
  того же промпта; после 2–3 попыток — стоп и вопрос человеку. Совпадает с
  нашим `max_attempts`, приём «поправка в промпт» можно взять в перегенерацию.
- **Деньги вперёд.** Оценка стоимости до генерации, показ пользователю,
  журнал фактических трат — их `logs/*.jsonl` = наш манифест + `estimate_cost`.

Чего в исходном репо смотреть не стали (переклонировать при нужде):
стилевые шаблоны Seedance под рекламу (`seedance-2-ugc.md` — «9-слойная UGC
формула», premium-reveal, product-hero, lookbook, feature-walkthrough),
пайплайны pixar/claymation целиком (4-битовая рекламная арка), скиллы Meta-рекламы
и YouTube-превью, `analyze-video` (кадры из референс-видео → обратная разработка
стиля — может пригодиться для workflow нарезок).
